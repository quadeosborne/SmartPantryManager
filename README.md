# SmartPantryManager

Database Choice: SQLite
I chose to implement SQLite using SQLiteOpenHelper for this application. Why: SQLite is a lightweight, serverless database that is built directly into the Android operating system.
It requires no external backend setup or internet connection, ensuring the app works perfectly offline. For a localized, single-user app like a pantry manager, SQLite provides the fastest and most reliable 
way to handle CRUD operations while ensuring data persists securely on the device after the app is closed.
